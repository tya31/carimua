# Foto-foto website CariMUA

Taruh foto di folder ini (`public/images/`) dengan **nama file persis** seperti di tabel.
Selama file belum ada, website menampilkan kotak 📷 berisi nama file yang dibutuhkan,
jadi kamu bisa lihat langsung posisinya di halaman.

Tips: kompres foto dulu (misalnya di https://squoosh.app) supaya website tetap cepat, idealnya < 400 KB per foto.
Format `.jpg` atau `.webp` (kalau pakai .webp, ganti juga ekstensi di kode).

| Nama file | Dipakai di | Ukuran disarankan | Isi foto yang cocok |
|---|---|---|---|
| `hero.jpg` | Beranda, foto besar kanan atas | 1200 × 1500 (potret 4:5) | Model dengan makeup glam, latar gelap |
| `hero-avatar.jpg` | Beranda, foto kecil di kartu melayang | 400 × 400 (persegi) | Close-up wajah |
| `service-wedding.jpg` | Beranda, kartu layanan Wedding | 600 × 800 (3:4) | Makeup pengantin |
| `service-wisuda.jpg` | Beranda, kartu layanan Wisuda | 600 × 800 (3:4) | Makeup wisuda |
| `service-party.jpg` | Beranda, kartu layanan Party | 600 × 800 (3:4) | Makeup pesta / glam |
| `service-photoshoot.jpg` | Beranda, kartu layanan Photoshoot | 600 × 800 (3:4) | Makeup editorial |
| `cta-mua.jpg` | Beranda, bagian "Kamu MUA?" | 1000 × 1250 (4:5) | MUA sedang merias |
| `login-side.jpg` | Halaman login, panel kiri | 1000 × 1400 (potret) | Foto suasana / beauty |

Setelah menaruh foto: refresh browser. Untuk website online, commit & push, nanti Vercel update otomatis.
